# GTM-Sim v0 多种子敏感性报告（Phase 2a 缺口 3 的一部分）

- 运行时间：2026-10-25（北京时间），由后台研究直接复跑，非转述。
- 配置：种子 0–9、42、123（共 12 个），每种子 200 账户、24 周，与
  `example_output.md` 同一套仿真器与基线（`gtm_sim.py` 未改动）。
- 数据性质：**全部合成数据，不是真实厂商数据，不得解读为真实转化率、收入
  或任何厂商的表现。** 本报告只回答“在 v0 合成设定下结论有多稳”，不回答
  “G+ 在真实世界是否有效”。

## 成对比较（逐种子计数，比均值更诚实）

- 有门 > 无门：**11 / 12**（唯一例外是种子 1：有门 0.237 < 无门 0.251）。
  这比 Phase 2a 原来的 3 种子抽查更强，但仍不是“恒成立”。
- 有门 > G：**8 / 12**。有门均值（0.315）只比 G（0.297）高 0.018，
  远小于两者各自的标准差（0.071 / 0.063）——**不能宣称有门递归优于 G**，
  只能说两者在同一档，递归的增量在合成设定下尚未被证实。
- 有门在单种子中主指标最高：7 / 12。
- 伤害面（12 种子均值）：有门声誉变化 -0.151，无门 -0.339，G -0.173。
  有门的“更少烧信任”在均值上成立，且与主指标方向一致，这是本报告
  最值得保留的一点——但同样只在合成设定下。

## 产量门槛分析（缺口 2 的预演，未改代码）

以“绝对管道 ≥ 200”作为参与排名的门槛做事后筛选：

- WAIT-heavy：12 个种子中 **0 个**达标（均值仅 77.0）——
  它在个别种子里主指标冲到 0.244 纯粹是分母太小，门槛一加上就出局，
  证实了 README 里“几乎不做刷比率”的担忧是真实的，不是假设。
- G+ 有门：11 / 12 达标（唯一未达标种子的管道为 193，贴近门槛）。
- 结论：**下一版必须把产量门槛写进排名规则**，而不是事后筛选；
  门槛值本身（200 只是本报告的演示值）需要在论文方法节里论证，
  不能事后挑一个对自己有利的数。

## 本报告没有解决的事（仍待办，按原优先级）

1. **OPE 方法论单元测试**（最优先）：用已知 logging policy 生成日志，
   以 DR / SNIPS 反推排序，检验 OPE 能否在已知真值下恢复排序。
   没有它，未来拿到真实日志也无法信任评估结果。
2. **产量门槛正式化**：把门槛写进仿真器排名逻辑并论证取值，
   而不是本报告的事后筛选。
3. **参数敏感性扫描**：声誉衰减系数、信任预算等设定值的扫描尚未做；
   本报告只换了随机种子，未换机制参数。
4. **公开面板真实采集**：仍只有 schema，未采集；先跑 T1 持续性基线。

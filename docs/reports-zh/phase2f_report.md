# Phase 2f 总报告：消融实验（静态 G / 工作流-only / 状态-only / 联合有门）

> 合成数据声明：以下全部为合成数据，不是真实厂商数据，不宣称任何真实
> 转化率、收入、厂商表现或跨厂商泛化。旧文件（gtm_sim.py、phase2d_*、
> paper-draft-v3.md 及全部更早文件）完整保留、未改动。本阶段新增文件
> 仅在 phase2a/ 内：phase2f_sim.py、phase2f_run.py、phase2f_results.json、
> phase2f_report.md（本文件）。仅 Python 标准库。

## 0. 预注册（实验前写定，本报告开头必须写明，结论按此执行）

- **若有门工作流+状态（B）不优于静态 G**，则结论进一步收缩为
  “门否决坏递归，递归增益在合成内亦未证实”。
- **若仅一层有效，则只报该层效应**，不得把联合效应归于两层。
- **若两层单独均无效而联合有效，需明确写为交互效应假设、不得拆分归因。**
- 统计纪律：1000 账户 / 10 种子 / 24 周，同一批种子配对比较；报均值、
  95% t 区间与胜负数；单一种子结果不得当结论；**空比较种子不得剔除，
  须明说**。本报告的“优于”判定标准为配对差的 95% t 区间不含零
  （与 2c/2d 同标准）；区间含零即判为“未证实”，不以均值符号或胜负
  多数改判。

## 1. 一句话结论（按预注册的 verdict：未证实并收缩）

- **Verdict：递归增益未证实并收缩。** 联合有门 B − 静态 G 真值差
  +0.0161（95% CI [−0.009, +0.041]，5 胜 / 2 负 / 3 平），区间含零，
  故触发预注册收缩条款：**结论收缩为“门否决坏递归，递归增益在合成内
  亦未证实”**。工作流-only 与状态-only 也均未达到“优于静态 G”的
  标准（见 §3），故不存在“仅一层证实”的情形，更不存在“两层单独
  无效而联合有效”的交互情形——交互效应假设不触发，不得提出。
- **门的否决价值在本批重跑中再次复现，且与 2d 逐种子完全一致。**
  B − C +0.0388（[0.019, 0.058]，10/10）；B − D +0.0313（[0.018, 0.044]，
  10/10）；C/D 宣称与真值排名翻转均为 10/10。门在合成内的价值仍是
  “否决坏递归”，不是“提升效率超过静态 G”。
- **与 2c/2d 结论的关系：2c 未被推翻，反而被扩展。** 2c 的“有门 ≈ G”
  原是阈值层结论；2f 在工作流+状态层上得到同一形态的结论
  （B ≈ 静态 G，区间含零），且 2d 的“B 优于无门/篡改”在本批重跑中
  逐种子复现。因此 2c 维持，2d 维持，新增的只是：递归增益在更高
  一层（工作流+状态）上同样未被证实。

## 2. 方法（与 2d 同口径，逐项对齐）

- **同一仿真器、同一信号分布、同一预算、同一主指标、同一假采纳定义、
  同一伤害指标。** 2f 直接复用 phase2d_sim 的 policy_d、run_policy、
  _gate_pass、_proxy_pipeline_per_trust、_tampered 与 gtm_sim 的账户生成/
  演化/评估（finalize_metrics）；主运行账户 make_accounts(n, seed)，
  验证集 make_accounts(200, seed+1000) / 8 周 / 种子 seed+2000，与 2d
  完全相同。信任预算 30.0 + 声誉 < 0.45 即 WAIT；门容忍：退订 +0.2、
  投诉 +0.1、信任上限 1.10 倍、wait_share < 0.95、真值 > 现任。
- **静态 G 臂（STATIC）：** 阈值层信任约束策略，无递归，全程固定配置
  {workflow: W0, state: S0, threshold: 0.40, lambda: 3.0}。
  与 Phase 2c 的 G 对齐：2c 的 G 就是同一阈值/λ的静态信任约束策略
  （gtm_sim 阈值 0.40、λ 3.0、信任预算硬约束）；2f 的 STATIC 是它在
  2d 仿真器（policy_d 的 W0/S0 分支）下的同一口径实现——W0 即基线 G
  的动作选择，S0 即快照观测意图。
  STATIC 与 2d 各臂的关系：它是 2d 所有臂的 epoch 0 起点配置
  （B/C/D 均从该配置出发）。一致性锚点已验证：B 的空比较种子
  （0、3、4）上 B 与 STATIC 的真值逐种子完全相等；W 的空比较种子
  与 S 的空比较种子上亦然（见 §3 末）。若该锚点不成立，说明仿真器
  口径漂移，本实验应作废——锚点成立，故口径可信。
- **工作流-only 有门臂（W）：** 仅工作流 W 递归、有门、评估器冻结，
  状态全程保持基线快照 S0。每 epoch 4 个候选全部翻转工作流
  （W0↔W1），状态恒为 S0，阈值/λ仅作 2d 式微调；绝不含状态翻转候选，
  绝不含工作流不变的纯阈值候选（否则消融不纯）。
- **状态-only 有门臂（S）：** 仅状态 S 递归、有门、评估器冻结，工作流
  全程保持基线 W0。每 epoch 4 个候选全部翻转状态（S0↔S1），工作流
  恒为 W0；绝不含工作流翻转候选，绝不含状态不变的纯阈值候选。
- **对照臂（B/C/D）：** 直接调用 phase2d_sim.run_arm 在本批种子上重跑，
  不挪用 phase2d_results.json 的数字。重跑结果与 2d 逐种子完全相等
  （B/C/D 真值逐种子 6 位小数一致，均值 B 0.3028 / C 0.2640 / D 0.2715
  与 2d 相同），证明同批种子配对有效、仿真确定、2d 数字可复现。
- **候选集与 2d 的关系（必须明说）：** 2d 每 epoch 4 个候选分别为
  工作流-only、状态-only、工作流+状态、工作流+阈值/λ变动；2f 的 W/S
  臂每 epoch 同样 4 个候选，但全部约束在单层内（翻转该层 × 阈值/λ
  微调组合），以保证“该层单独效应”可归因。候选数量、验证集、门
  均相同；候选构成不同是消融设计本身，不是口径漂移。
- **空比较定义：** W/S/B 的空比较 = 2 个 epoch 均未采纳、参数与初始
  相同。STATIC 的“空比较”恒为 10/10，但含义不同——不是“门未变”，
  而是“按设计从不尝试递归”，报告中不得把两者混为一类证据。
  24 周 = 2 次递归评估（第 8、16 周后），故每臂每种子 2 个 epoch 槽位，
  10 种子共 20 个槽位；采纳/否决总数以 20 为分母。

空比较种子不得剔除，须明说（本节最重要）：
- 全部 10 种子均保留在配对计算中。空比较种子上的配对差恒为 0
  （门未变 = 静态配置），它们把均值拉向零、把胜负数稀释为平局，
  而不是抬高优势——若剔除空比较种子，B−STATIC 的非空种子均值将升为
  +0.0230（5 胜 / 2 负，n=7），W−STATIC 的非空种子均值将升为 +0.0328
  （4 胜 / 0 负，n=4）。本报告不以剔除后的数字作结论，原因：
  剔除是以“门是否采纳”这一事后变量为条件，属于选择偏倚——采纳的
  种子恰是验证集上看起来好的种子，主运行上的“采纳种子子集优势”
  不能读成递归的因果效应。剔除数字仅作敏感性披露，不得进入论文主结论。
- 一致性锚点：B 与 STATIC 相等的种子恰为 B 的空比较种子 [0, 3, 4]；
  W 与 STATIC 相等的种子恰为 W 的空比较种子 [1, 3, 4, 7, 8, 9]；
  S 与 STATIC 相等的种子恰为 S 的空比较种子 [0, 1, 2, 3, 4, 6]。
  三者均精确成立，无一例外。

解读（必须同时报的四点）：
1. **联合递归未胜过静态 G，且不是“差一点”的修辞问题。**
   B−STATIC 区间 [−0.009, +0.041] 含零、且含 2 个负向种子（种子 7
   −0.0305、种子 9 −0.0333）：门在验证集上通过的采纳，在主运行上
   可以为负——门保证的是验证集改进，不是主运行改进。验证集（200
   账户 / 8 周 / 独立种子）与主运行（1000 账户 / 24 周）在账户总体、
   时长、已采纳配置的后续演化上均不同，验证增益向主运行的迁移本身
   就是未被证实的环节。这是 B ≈ STATIC 的最直接机制解释，不是噪声借口。
2. **工作流-only 方向一致但未达标准，不得报为“仅一层证实”。**
   W−STATIC 的 4 个非平局差分全部为正、无一为负，均值 +0.0131，
   但 95% 区间下限为 −0.001（勉强含零）。按预注册的区间标准，它仍是
   “未证实”。把它报为证实，就是把“方向好看”偷换为“统计证实”。
   诚实表述只能是：工作流层是三臂中最有希望的下一候选（非平局 4/4
   为正），但在本实验量级下未过线，需要更大样本或更长时程的独立
   检验，而不是在本报告中升级。
3. **状态-only 是干净的零。** S−STATIC 均值 −0.0007、区间对称含零、
   非平局 2 胜 2 负；S 的 4 次采纳中有 2 次在主运行上为负（种子 5
   −0.0507、种子 7 −0.0305），且 B−S 的正向均值（+0.0168）同样区间
   含零。状态表示 S1（EMA + 趋势 + 疲劳调整）在本合成设定内没有可
   归因的单独效应；联合臂 B 的正向均值不能拆分归因于状态层。
4. **联合不优于任一单层，交互假设不触发。** B−W +0.0030（区间含零，
   2 胜 4 负）、B−S +0.0168（区间含零）——联合臂甚至在胜负数上不
   优于工作流-only（B−W 为 2 胜 4 负）。预注册的交互条款要求“两层
   单独均无效而联合有效”，本实验是“联合亦无效”，故交互效应假设
   既无触发条件、也不得作为事后解释提出。B 的均值高于 W、S 两臂
   均只是均值符号，不构成效应。

对论文（v4 方向 A+）的直接含义：工作流+状态递归的效率主张不得
进入核心章作正向主张；可写进论文的是三句收缩后的句子——(1) 门在
合成内稳健地否决坏递归（B 优于 C/D，逐种子复现）；(2) 有门递归在

## 6. 未做的事与局限（红线）

- 未访谈、未对外联络、未爬取或购买个人数据、未用真实厂商内部数据；
  全部合成数据，不得宣称真实厂商效果。
- 未设吸收态臂与评估器分离臂，故 2d 对信任预算、VRI、评估器分离的
  verdict 不受本实验影响，也不被本实验加强。
- 局限 1（验证迁移）：门只保证验证集改进，主运行改进未被门保证；
  种子 7、9（B）与种子 5（S）的负向主运行差分是该局限的直接证据。
- 局限 2（候选集构成）：2f 的单层候选集是 2d 候选集的约束版，不是
  2d 候选集的子集复现；若 2d 的混合候选（工作流+状态同时翻转）本身
  有独特价值，单层消融会低估联合臂——但 B 臂本身用的就是 2d 混合
  候选集，B−STATIC 仍含零，故该担忧不改变主 verdict，只影响对
  “联合为何无效”的机制解释。
- 局限 3（样本量）：10 种子下 W−STATIC 区间下限仅 −0.001，扩大种子
  数可能使 W 过线或归零——两种结果都可能，本报告不预测；W 的下一
  步应是独立的、预注册的更大样本检验，而不是对本批数据的事后挑选。
- 局限 4（空比较稀释）：6/10（W、S）与 3/10（B）的空比较种子是门
  保守性的直接后果：门越保守，越多种子恒等于静态，配对差越被拉向零。
  这不是统计瑕疵，而是“有门递归”这一策略本身的性质——它的期望
  增益天然被“经常不变”所稀释；任何声称递归增益的检验都必须同时
  报告空比较率，否则均值会被误读。

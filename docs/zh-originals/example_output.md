## 怎么读这张表（只看主指标会读错）

1. **有门递归是本种子下的主指标最高者**，且伤害指标在活跃策略中最低
   （退订 0.51、投诉 0.10、声誉变化 -0.151），并有 1 次否决/回滚记录：
   两轮递归中一轮候选通过（阈值 0.40 → 0.35），一轮被门否决。
   最终参数：`threshold=0.35, lambda=3.0`。
2. **无门递归是关键对照**：回复数 131（高于有门的 80），但主指标只有 0.154，
   退订率 1.05、声誉变化 -0.354、WAIT 占比从 0.74 掉到 0.53 ——
   以“回复量”为目标的递归确实学会了“发更多”，代价是信任。
   这正是 Phase 2 H7 在合成设定下的方向性复现，**不是真实世界的证明**。
3. **回复率贪心绝对管道最高（773），但声誉变化 -0.853 是灾难性的**：
   它的管道是烧信任换来的。只报“管道最高”而不报声誉变化，在本基准里视为无效解读。
4. **WAIT-heavy 伤害最低但几乎不产生管道（30.0）**：克制本身不是胜利，
   必须同时看绝对管道量。主指标必须与绝对量、WAIT 占比一起读。

## 换种子稳健性抽查（不在本表内，仅作 README 说明）

- seed 7：G+ 有门 0.252 > 无门 0.221；G 为 0.284（有门略低于 G）。
- seed 123：G+ 有门 0.284 > 无门 0.253；G 为 0.275。
- 结论：**有门 > 无门在三个种子上方向一致；有门 > G 并不稳定**，
  且 WAIT-heavy 的主指标在不同种子间波动极大（0.057 / 0.236 / 0.232），
  因为它的触达数很少、分母很小 —— 这是 v0 主指标的已知弱点，
  下一版必须加“最小产量门槛”或改用带产量约束的帕累托比较。
  本示例绝不构成“G+ 已被证明有效”的宣称。

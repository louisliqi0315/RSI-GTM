# Phase 2j 预注册（全量运行前写定，结论按此执行）

合成数据声明：全部为合成数据，不是真实厂商数据，不宣称真实转化率、
收入、厂商表现或跨厂商泛化。旧文件（gtm_sim.py、phase2d_*、phase2f_*、
phase2g_*、phase2h_*、phase2i_*、paper-draft-v7.md 及全部更早文件）
完整保留、未改动。

## 0. 问题与唯一改动原则

- 2i 之后深度 1 在三工作流空间里依然复现，且有两个未解问题：
  (1) 臂 B 不是严格超集（每工作流只有 3 种微调变体，缺少“thr 不变、
  lam−1”变体），丰富度判定被降级为“在本候选集定义下未证实有效，
  严格超集检验未做，不得直接断言丰富度无关”；
  (2) 更直接的机制解释是“第一轮采纳后必须在同一验证分布上再次
  击败现任”——现任棘轮 / 验证集优胜者诅咒，与 W2 的存在与否无关。
- 本阶段一次检验这两个问题，每臂与对照只差一处，不得同时改两处。
- 三臂（A0、C、D）加静态基线共享：1000 账户 / 30 种子（0–29）/
  48 周、种子配对、主运行 epoch 8 周（48 周内 5 次评估，在第 8、16、
  24、32、40 周后）、门容忍（退订 +0.2、投诉 +0.1、信任上限 1.10 倍、
  wait_share < 0.95、真值 > 现任）、验证集规模 200 账户 / 8 周、
  静态 G 定义（全程固定 {W0, S0, threshold 0.40, lambda 3.0}）、
  主指标（冻结评估器真值管道/信任 pipeline_per_trust）、假采纳定义、
  伤害指标。D 只改验证种子的独立性，不改验证集规模（200 账户）
  与时程（8 周），不改门容忍。

## 1. 四臂定义

- STATIC（静态 G）：从不评估候选、从不递归，全程固定基线配置。
  其 empty_comparison 恒为 True，含义是“按设计从不尝试递归”，
  不得与 A0/C/D 的“门未变”混为一类证据。
- 对照臂 A0（复现 2i 臂 A）：旧二元候选集不变
  （phase2f_sim._candidates_w_only，翻转工作流 × 阈值/λ微调，
  共 4 个候选），主运行与验证集均用原 policy_d；验证集各 epoch
  复用同一口径：账户种子 seed+1000、运行种子 seed+2000
  （与 2f/2g/2h/2i 完全相同）。A0 是本阶段的同批对照，
  用于 C 与 D 的各自比较。
- 臂 C（严格超集复测）：与 A0 的唯一差别是候选空间补齐——
  每工作流 4 变体 × 2 个非现任工作流（W1、W2）= 8 候选，
  含“thr 不变、lam−1”变体（见 §2）；验证集复用方式与 A0
  完全相同（账户种子 seed+1000、运行种子 seed+2000，各 epoch
  复用）。主运行与验证集均用 policy_i（因 W2 可能被采纳，
  主运行必须能执行 W2；policy_i 对 W0/W1 与 policy_d 逐行一致）。
- 臂 D（独立验证种子检验，更优先的机制臂）：与 A0 的唯一
  差别是验证集——每 epoch 用独立验证种子（见 §3 的可执行
  种子规则，不得与主运行种子冲突）；候选集与 A0 完全相同
  （旧二元、4 变体），主运行与验证集均用原 policy_d，
  门容忍、验证集规模与时程、静态基线、主指标全部与 A0 相同。
  D 检验的假设是：现任不再是在同一验证分布上被选出来又被
  同一分布保护的，挑战者每轮面对新鲜验证分布。

## 2. 臂 C 候选集定义（可执行，写在代码里）

- 设现任工作流为 w，现任阈值 thr、λ lam；另两个工作流为
  {W0, W1, W2} \ {w}，按 W0、W1、W2 顺序排列，记为 a、b。
- 每工作流 4 种阈值/λ组合（与 A0 的 _candidates_w_only 完全一致）：
  (1) 基线 (thr, lam)；
  (2) (min(0.8, thr + 0.05), lam)；
  (3) (max(0.15, thr − 0.05), max(1.0, lam − 1.0))；
  (4) (thr, max(1.0, lam − 1.0))——即 2i 臂 B 缺少的
  “thr 不变、lam−1”变体。
- 候选 = [a 的 4 变体，b 的 4 变体]，共 8 个；状态恒 S0；
  绝不含状态翻转候选（本阶段仍是工作流-only 检验）。
- 候选数量 8 vs A0 的 4 是严格超集本身的一部分（新增 W2 维度
  × 补齐变体），不是额外改动；报告中必须明说候选数不同，
  且不得把 C 的采纳数直接与 A0 的采纳数作“同等机会下”的
  比较而不注明候选数差异。

## 3. 臂 D 独立验证种子规则（可执行，写在代码里）

- 设某次递归评估为本臂的第 e 次评估（e = 1、2、3、4、5，
  对应第 8、16、24、32、40 周后的评估）。
- 该次评估的验证集：账户种子 = seed + 1000 + e × 10000，
  运行种子 = seed + 2000 + e × 10000。
  即 e=1 时为 seed+11000 / seed+12000，e=5 时为
  seed+51000 / seed+52000。
- 该规则保证：(a) 各 epoch 的验证样本互不相同（新鲜分布）；
  (b) 账户种子与运行种子之间恒差 1000，与 A0 的口径结构一致；
  (c) 验证种子（≥ seed+11000）与主运行种子（seed，0–29）
  以及 A0/C 的验证种子（seed+1000、seed+2000）均不冲突；
  (d) 同一 epoch 内，现任与全部候选共用该 epoch 的验证样本
  （同一 epoch 内的比较是公平的），跨 epoch 才换样本。
- D 的主运行随机数流不受验证种子影响（验证集账户与运行
  种子均独立于主运行 rng）；主运行账户仍为 make_accounts(n, seed)。

## 4. 递归深度定义（与 2i 一致）

- 采纳数：每种子全程被门采纳的次数；递归深度即采纳数。
- 递进采纳：某次采纳的新工作流 ≠ 该次采纳之前上一次采纳
  所离开的工作流（例如 W0→W1→W2 是递进，W0→W1→W0 不是；
  首次采纳无上一次可比，不计入递进）。
- 报告须同时报采纳数、递进采纳数、≥2 次采纳的种子数、
  至少 1 次递进采纳的种子数、最终工作流分布。

## 5. 主指标与判定（事先写死，不事后改动）

- 主指标：48 周终点真值管道/信任，配对差（臂 − STATIC）的
  95% t 区间（全部 30 种子，含空比较种子）。另报 C−STATIC、
  D−STATIC、C−A0、D−A0 四组配对差；C 与 D 的比较只作
  各自是否打破深度 1 的并列陈述，见 §6。
- 判定 D（现任棘轮 / 验证集优胜者诅咒是否成立）：
  - 若 D 出现 ≥2 次采纳的种子数 > 0，或 D 空比较率 < 60%，
    记为“现任棘轮 / 验证集优胜者诅咒是深度 1 的主因之一”。
  - 若 D 仍深度 1（≥2 次采纳的种子数为 0 且递进采纳总数为 0）
    且空比较率 > 60%，记为“独立验证种子未打破深度 1，
    瓶颈不在验证集复用”。
  - 介于两者之间（例如空比较率下降但仍 ≥ 60%，或有递进采纳
    但 ≥2 次采纳仍为 0），记为“部分缓解，未证实为瓶颈主因”，
    不得写成已证实。
- 判定 C（严格超集下丰富度是否有效、先前降级是否可解除）：
  - 若 C 出现 ≥2 次采纳的种子数 > 0，或 C 空比较率 < 60%，
    记为“严格超集下丰富度有效，先前降级可解除”
    （解除的范围仅限“丰富度”这一分支，不触动其他 verdict）。
  - 若 C 仍深度 1（≥2 次采纳的种子数为 0 且递进采纳总数为 0）
    且空比较率 > 60%，记为“丰富度可较干净地排除为瓶颈”。
  - 介于两者之间，记为“部分缓解，未证实有效”，不得写成有效，
    先前降级维持。
- 边界规则：空比较率恰为 60% 时不判“低于 60%”；
  ≥2 次采纳的种子数恰为 0 时不判“出现”。

## 6. 禁止事后操作、比较声明与必须全报

- 不得降低验证门、放宽采纳标准、剔除空比较种子来制造显著性；
  不得改门容忍或验证集规模（D 只改种子独立性，不改规模与时程）。
- 必须全报：各臂空比较种子数与空比较率、逐轮次采纳分布
  （第 8、16、24、32、40 周后各轮的采纳种子数）、递归深度分布、
  递进采纳数、最终工作流分布、假采纳数、否决数、伤害指标
  （退订率、投诉率、声誉变化的配对差）、剔除空比较后的敏感性
  （仅披露，不进主结论）。
- 比较声明：C 与 D 与对照的差别不同（C 改候选空间，D 改验证
  种子独立性），不能直接说谁更优于谁，只能各自报是否打破深度 1；
  C−D 配对差可作描述性数字报出，但不得据此判 C 或 D 的机制
  更优。不得把任何一臂的 48 周效应量与 2g 的 24 周效应量平均；
  不得把 C 或 D 的结果写成“工作流递归增益已证实”或
  “递归随轮次变强”（除非判定另行决定并带时程限定表述）；
  不得把 C 或 D 的结果用于升级联合、状态、信任预算、采纳规则、
  评估器分离的 verdict（本阶段未设这些臂）。
- 一致性锚点：A0/C/D 空比较种子上该臂与 STATIC 的 48 周真值
  必须逐种子完全相等；若不成立，说明口径漂移，本实验作废。
  另设冒烟检验：50 账户 / 2 种子 / 16 周（epoch 8 周）下 C 候选集
  含 8 候选且无崩溃、D 各 epoch 验证种子互不相同且无崩溃、
  A0 空比较锚点成立，通过后才启动全量。
- 全部合成数据，不得宣称真实厂商效果、转化率或跨厂商泛化。

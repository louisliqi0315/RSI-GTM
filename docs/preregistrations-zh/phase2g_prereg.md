# Phase 2g 预注册（全量运行前写定）

- 设计：1000 账户 / 30 种子（0–29）/ 24 周，种子配对。
- 对比：工作流-only 有门（W）vs 静态 G（STATIC），定义与 2f 完全一致：
  W 仅 W1 递归、有门、评估器冻结，状态恒 S0；STATIC 为阈值层信任约束
  无递归，全程固定 {W0, S0, threshold 0.40, lambda 3.0}。
  代码直接复用 phase2f_sim.run_arm_f，不改任何参数、门容忍、
  验证集口径（200 账户 / 8 周 / 独立种子）或候选生成。
- 主判定：配对差（W − STATIC，真值管道/信任）的 95% t 区间。
  若区间下界 > 0，记为合成内工作流递归增益成立（仍限合成设定，
  不得推导真实厂商效果）；若区间仍含零，记为未证实。
- 禁止事后操作：不得降低验证门、放宽采纳标准、剔除空比较种子
  来制造显著性；空比较种子、采纳/否决、伤害指标必须全报。
- 敏感性（仅披露，不进主结论）：剔除空比较种子后的配对差。
- 若 verdict 为未证实：工作流层不再优先同口径重复，下一检验必须
  改设计（更长时程、更密 epoch 或不同候选生成），而非加种子。
- 全部合成数据，不得宣称真实厂商效果、转化率或跨厂商泛化。
